# pm-claude-skills

Claude skills that turn everyday product management work into repeatable, reviewable workflows.

> 🚧 **Work in progress.** Generic versions of the skills I use day to day are being added here, one at a time.

## Why
Most PM writing follows the same patterns: PRDs, briefs, epics, decks. Encoding those patterns as skills gives consistent structure, built-in quality checks and much less blank-page time, while the PM keeps the judgment calls.

## Skills (planned)
| Skill | What it does | Status |
|---|---|---|
| `prd-writer` | Drafts a PRD from a problem statement, anchored on a standing user persona, with goals, non-goals, requirements and success metrics | Planned |
| `product-brief` | Turns rough notes into a one-page product brief for stakeholder alignment | Planned |
| `epics-from-brief` | Breaks an approved brief into epics and user stories with acceptance criteria | Planned |
| `branded-deck` | Builds a slide deck from a brief using a consistent visual template | Planned |
| `instructions-updater` | Takes an existing AI agent instruction file plus change notes and produces the updated, versioned instructions | Planned |

## How to use
Each skill will live in its own folder with a `SKILL.md`. Copy the folder into your Claude skills directory, or upload it in Claude settings.
